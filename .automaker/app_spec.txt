  <project_name>StoryMaker</project_name>

  <overview>
    StoryMaker is a real-time story creation application built with React and Electron, featuring a Kanban board dashboard for organizing narrative elements through customizable &apos;story cards&apos;. The application enables writers and storytellers to visually structure their stories using drag-and-drop functionality. Users start with an empty Kanban board and access a drawer containing categorized story cards that can be searched, filtered, and organized. The system supports full CRUD operations for story cards (creating from scratch or duplicating from templates), Kanban board categories, and multi-project management. A key feature is the ability to create genre-specific templates for Kanban categories, allowing users to quickly set up story structures tailored to different narrative styles. The drawer includes a keyword-based search with bubble button UI for frequently used keywords. Future plans include monorepo architecture for backend services and MediaPipe integration for text extraction from images.
  </overview>
